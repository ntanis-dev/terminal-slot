Terminal Slot

A slot machine that fits in a terminal.

A terminal adaptation of Amatic’s "Hot Scatter" slot: spinning reels, paylines, and payouts, rendered entirely in text. Built to see how much of a physical machine survives when the only output device is a character grid.

View source

  • Real reels

    Spins, stops, and paylines follow the original machine’s structure rather than a random number and a message.

  • Nothing to install

    Runs anywhere Node runs. No graphics stack, no window, just a terminal.
